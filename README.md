# Инструкция по запуску кода

Для запуска экспериментов выполните следующие команды:
1. DQN 
```bash
python3 ./run.py ./configs/dqn_setup1.py
```
```bash
python3 ./run.py ./configs/dqn_setup2.py
```

2. A2C
```bash
python3 ./run.py ./configs/a2c_setup1.py
```
```bash
python3 ./run.py ./configs/a2c_setup2.py
```
После выполнения команды загрузятся веса моделей и проведётся eval() на рандомных Grid-полях. Можно поменять seed для поля (в конфиг файле например configs/dqn_setup1.py нужно изменить поле seed. Для генерации других расположений агента на картинках можно поменять массив seed'ов. Можно также провести обучение модели достаточно поменять 'train' : False на True. 
Для запуска на векторизованной среде в конфиг-файле необходимо написать:
```bash
'env' : "vector",
'count_vec' : 3, # количество параллельных сред
```
